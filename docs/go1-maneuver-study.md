# Go1 复合指令与能力保留对照（2026-09-14）

本轮完成六组续训及独立复核，未找到满足全部能力保留门槛的新模型；保留已有基准。增加 `maneuver-switching` 评估：斜向后退、横移同时转弯、原地旋转与停车。新增套件已接入受管 CLI、逐环境首回合验收、源码快照和离线运动回放。旧套件的指令及口径不变。

## 发现的问题

上一轮的 1650 轮模型 `go1-stop-stops-s0-1650-20260913` 在新套件开发集（种子 0/1/2，各 32 个环境，每次 60 秒）中没有跌倒，但斜向后退的全时段达标比例只有 81.7%–84.6%，低于 90% 门槛。连续 0.5 秒达标的环境比例最差只有 18.75%。原先通过的固定指令和横移停车测试未覆盖这一组合动作。

每个切换套件含六个等长阶段。新套件顺序如下；前两轴为机体局部线速度（m/s），第三轴为偏航角速度（rad/s）。

| 阶段 | 指令 |
|---|---|
| 站立 | `[0, 0, 0]` |
| 斜向后退 | `[-0.5, -0.3, 0]` |
| 左横移同时左转 | `[0, 0.3, 0.5]` |
| 右横移同时右转 | `[0, -0.3, -0.5]` |
| 原地左转 | `[0, 0, 0.8]` |
| 停车 | `[0, 0, 0]` |

所有环境从第一次试验开始计数，跌倒后不会重新加入后续阶段。终止帧计入误差，但不计为跟踪成功；达标时间分母包含全部初始环境与预定阶段时长。

## 对照设计

从同一 1650 轮模型恢复模型参数和 Adam 状态，保留 `lateral-stop-v1` 指令分布与固定学习率 `0.0001`，每组继续训练 150 轮、512 环境、24 步 rollout、4 线程。训练种子为 0 和 1，三个奖励配置共六组，合计 11,059,200 次环境转换。环境和随机数状态重新初始化，属于续训，不是仿真状态的无缝恢复。

| 组别 | 平移奖励权重 | 转向奖励权重 |
|---|---:|---:|
| control / tracking-turn-v1 | 2 | 1 |
| balanced / tracking-balanced-v1 | 3 | 1 |
| strong / tracking-strong-v1 | 3 | 1.5 |

训练前将计划写入 [plan.json](../runs/go1-maneuver-audit-20260914/plan.json)。开发集种子 0/1/2，四个套件为 `extended`、`switching`、`lateral-switching`、`maneuver-switching`，每个试验 32 环境 × 3000 步。旧模型已有三个旧套件的同种子完整结果，本轮复用并重新验证；新套件实际运行。

候选须通过四个套件的全部验收，且相对 1650 轮基准满足：复合动作平面 RMSE 至少降低 5%；横移平面 RMSE、原动态平面 RMSE、三条基本移动指令的合并角速度 RMSE，以及每条基本移动指令的平面 RMSE，分别不得增加超过 10%。在满足条件的模型中按复合动作平面 RMSE 最小排序。没有候选满足时保持空选择，不降低门槛。

套件验收要求：存活率 100%、平面 RMSE ≤ 0.15 m/s、角速度 RMSE ≤ 0.2 rad/s；切换套件同时要求连续稳定达标环境比例 ≥ 80%、全时段达标比例 ≥ 90%。阈值逐种子、逐指令和逐阶段检查，汇总 RMSE 按实际有效帧数加权。

## 开发集结果

六组均未满足完整保留门槛，[冻结选择](../runs/go1-maneuver-audit-20260914/selection.json) 的 `selected` 为 `null`。三个模型通过四个套件的绝对阈值，但相对原模型的转弯精度退化仍超限，因此没有替换当前基准。

| 组别 / 种子 | 通过套件数 / 4 | 复合动作平面 RMSE（m/s） | 最差阶段达标时间比例 | 固定横移误差变化 | 基本移动角速度误差变化 |
|---|---:|---:|---:|---:|---:|
| control / 0 | 2 | 0.08148 | 69.33% | +26.7% | +16.1% |
| balanced / 0 | 4 | 0.07209 | 93.95% | -21.1% | +22.3% |
| strong / 0 | 4 | 0.07317 | 94.60% | -11.5% | +52.2% |
| control / 1 | 1 | 0.07796 | 86.48% | +22.3% | +6.2% |
| balanced / 1 | 4 | 0.07131 | 93.03% | -23.3% | +14.3% |
| strong / 1 | 2 | 0.07971 | 85.62% | +15.0% | +4.1% |

表中变化均相对 1650 轮基准，负值代表误差下降；种子列是训练种子，各行均使用相同的三个开发评估种子。两个 balanced 模型都改善横移与复合动作，但角速度误差分别增加约 22.3% 和 14.3%，超过 10% 保留门槛。增加转向奖励的 strong 配置没有稳定解决这一取舍。

补充固定斜向后退诊断（种子 0，32 环境，60 秒，去掉前 2 秒）中，balanced / 0 将右斜后退的前向平均误差从 0.0464 降至 0.0119 m/s，侧向从 0.0478 降至 0.0336 m/s；偏航速度波动 RMS 从 0.0279 增至 0.0347 rad/s。这支持“减少欠跟踪、同时增加部分波动”的观察，不能代替四套件能力保留验收。原始逐帧数据与诊断脚本保存在本轮审计目录。

## 独立复核与最终决定

原选择为空后，另行冻结 [诊断复核计划](../runs/go1-maneuver-audit-20260914/diagnostic-holdout-plan.json)，在通过四套件绝对阈值的模型中选取复合动作平面 RMSE 最低的 balanced / 1，用未参与筛选的种子 100/101/102，与原基准和同种子、同训练量的 control / 1 对比。该步骤用于确认退化与改善，不改变原选择规则，也不将诊断候选升级为推荐模型。

| 模型 | 通过套件数 / 4 | 复合动作平面 RMSE（m/s） | 斜向后退最差达标时间比例 | 固定横移平面 RMSE（m/s） | 基本移动角速度 RMSE（rad/s） |
|---|---:|---:|---:|---:|---:|
| 1650 轮基准 | 3 | 0.07398 | 81.07% | 0.06090 | 0.02707 |
| 1800 轮 control / 1 | 1 | 0.07763 | 84.38% | 0.07445 | 0.02869 |
| 1800 轮 balanced / 1 | 4 | 0.07077 | 93.70% | 0.04662 | 0.03091 |

三种模型各完成 1,248 次 60 秒试验，均没有跌倒。balanced / 1 通过 405 项绝对阈值检查，但复合动作平面 RMSE 只降低 4.3%，未达到预设 5%；基本移动角速度 RMSE 增加 14.2%，左转和右转平面 RMSE 分别增加 26.7% 和 17.8%，均超出 10% 保留门槛。固定横移误差下降 23.4%，原动态平面误差增加 3.2%。因此本轮交付新的复合动作评估与完整对照证据，保留 1650 轮模型作为已有测试范围内的基准；其复合斜向后退不足仍然存在。

## 运行方式

```bash
python -m embodiedforge.recipes evaluate \
  --task go1-joystick \
  --run runs/go1-stop-stops-s0-1650-20260913 \
  --suite maneuver-switching --seeds 0 1 2 \
  --num-envs 32 --steps 3000 --threads 4 \
  --min-survival-fraction 1 --max-planar-rmse 0.15 --max-yaw-rmse 0.2 \
  --min-settled-fraction 0.8 --min-tracking-fraction 0.9 \
  --record-motion --output runs/go1-maneuver-local-check
```

输出目录必须尚不存在。当前基准在这组门槛下应返回退出码 2（未通过验收），而非训练或运行故障。查看 `acceptance.json` 可以定位失败阶段，HTML 回放记录环境 0 的真实首回合骨架轨迹。
