# Go1 横移与指令切换优化

本轮从上一轮选出的 `go1-yaw-fresh-turn-s11-1200-20260913` 出发，目标是在保留角速度跟踪收益的同时，降低横移与动态指令切换误差。原模型、此前的评估结果和失败记录均保留。

## 问题定位

评估种子 0、32 个环境的固定横移轨迹中，排除最初 2 秒后，目标为 ±0.3 m/s，原模型的平均横移速度约为 +0.225 / −0.213 m/s。对应侧向稳定偏差为 −0.0748 / +0.0866 m/s；侧向波动 RMS 约为 0.0174 m/s，主要问题是速度偏低。前后方向还存在约 0.0315 / 0.0388 m/s 的波动。

在原有六阶段动态套件中，停车后启动左转的前两秒，前向 / 侧向 RMSE 为 0.1665 / 0.0941 m/s，而该阶段后八秒分别为 0.0242 / 0.0223 m/s。固定速度误差与切换瞬态需要分别测量。

逐步数据、分解脚本及实测图表在 `runs/go1-response-audit-20260913/` 的 `*-diagnosis.json`、`*-trace.npz`、`diagnosis.png` / `.svg` 中。图中瞬态阴影表示环境间标准差，不能解释为置信区间。

## 可复用实现

- `--go1-command-profile lateral-v1` 将重采样时侧向轴启用概率从 0.25 提到 0.75，保留其他采样参数。新训练默认仍为 `original`；续训和评估继承配置，checkpoint 与运行元数据必须一致。
- `tracking-strong-v1` 使用 `track=3.0, turn=1.5`，保留两项跟踪奖励的 2:1 比例。已有奖励配置含义保持稳定。
- `--go1-learning-rate 0.0001` 支持固定学习率及后续继承，恢复 Adam 状态后在首轮更新前生效；每轮指标记录实际值。未覆盖时保留原累计轮次退火。
- `--suite lateral-switching` 连续执行站立、左横移、右横移、后退、斜向前进、停车，各阶段十秒。沿用首回合、终止帧、连续达标和全时段达标比例校验，并输出带阶段标签的真实刚体轨迹回放。

新增分布的专项测试验证：相同种子下，其他轴和随机数消费保持一致；评估强制输入相同指令时，物理初态及逐步响应完全相同。训练分布变化不会改变固定指令评估环境。

## 实验设计

所有正式续训从同一份 1200 轮模型及 Adam 状态出发，每组均为 512 环境 × 24 步 × 300 次更新，新增 3,686,400 次转换，累计 1500 轮。物理与学习器均使用 CPU、4 线程；任务语义为 `transition-v2`。环境和随机数状态在续训开始时重新初始化，这不是恢复仿真轨迹的逐步续跑。

第一阶段是奖励配置（`tracking-turn-v1` / `tracking-balanced-v1`）与指令分布（`original` / `lateral-v1`）的 2×2 对照，每组三个训练种子 0/1/2，共 12 份模型。开发评估固定为种子 0/1/2；独立评估预留 30/31/32。

观察第一批开发结果后，第二阶段探索 `tracking-strong-v1`，使用两种指令分布、三个训练种子，共六份模型，另预留 40/41/42。第三阶段探索固定学习率 0.0001，在原跟踪奖励、增强跟踪奖励及增强跟踪加横移采样三个配置中各训练三个种子，共九份模型，另预留 50/51/52。后两阶段明确属于受前期开发结果启发的探索，不是最初预先设定的对照组。

三个阶段分别选择模型，条件不因结果调整：

1. 32 环境、3000 步的原动态套件和十项扩展固定指令全部存活；各项平面 RMSE ≤ 0.15 m/s、角速度 RMSE ≤ 0.2 rad/s，动态连续达标比例 ≥ 0.8、全时段达标比例 ≥ 0.9。
2. 相对起始模型，原动态平面 RMSE 至少降低 5%，合并左右横移平面 RMSE 至少降低 15%。
3. 三条基本固定移动指令合并角速度 RMSE 不增加超过 10%；每条移动指令的平面 RMSE 也不增加超过 10%。
4. 在满足上述条件的候选中，选左右横移合并平面 RMSE 最低者；没有合格候选时不选模型。

所有合并 RMSE 都按实际观测帧加权平方后开方。候选先根据开发集冻结，再执行独立评估；新增连续横移套件用于额外检查，不替换原有套件或放宽门槛。

## 结果

本轮完成 33 组正式训练，合计 110,592,000 次状态转换，不含复现、短测和评估。前 27 份模型均新增 300 轮；后六份停车模型各新增 150 轮。

## 停车训练与选择

追加六组受控实验，从横移采样的 1500 轮模型出发，均以学习率 0.0001 新增 150 轮。对照保留 `lateral-v1`，处理组使用 `lateral-stop-v1`：每次重采样额外以 10% 概率将完整速度向量置零，覆盖被保留的轴。

第一套规则要求相对中间的 1500 轮模型，各项误差不增加超过 10%，且三个套件全部通过；这些较严格结果完整保留。首个停车开发结果显示，急停可以改善，但会牺牲部分中间横移收益。随后另做探索性选择：复用本轮最初相对 1200 轮模型的全部改善门槛，再加上新横移切换验收。该选择在独立种子 80/81/82 评估前冻结，未修改第一套规则或其结果。

已核对 4 组完整续训复现；每组模型和 Adam 优化器的 55 个张量、全部元数据均一致，文件逐字节相同。复现执行候选运行内的冻结源码；哈希及命令在 `reproduction-verification.json`、`reproduce.py` 中。

- 核心测试 387 项通过，52 项因可选依赖跳过；独立 Go1 SDK 环境中的 13 项检查全部通过，包括与原始 mjbatch 的数学等价检查。
- 新指令配置、学习率及旧模型缺省值的继承通过实际训练/评估验证；四类 checkpoint 元数据不一致会在评估前拒绝。
- 最终 wheel 实际安装后通过新横移套件，执行其自身源码快照；没有依赖工作区实时修改。
- 原横移候选、最终候选回放的阶段边界、交互和浏览器错误检查保留在审计目录。
